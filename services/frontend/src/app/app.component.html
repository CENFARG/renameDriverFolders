🚀 Guía de Configuración Express

1. ID y Estructura: El ID es el nombre técnico (sin espacios). La 'Carpeta Origen' es el ID de Drive que la IA vigilará.

2. Trigger: 'Manual' para ejecutar a pedido. 'Scheduled' para automatizar por fecha/hora.

3. Motor IA: Elige modelos 2.5 para velocidad o 3.0 para alta complejidad estructural.

4. Instrucciones: Dile a la IA exactamente cómo renombrar. Ej: "Extrae el CUIT y ponlo al principio".
